# Volunteer Hours Tracker

A Python application for recording volunteer service, tracking hours, and reviewing community impact. It includes a menu-driven terminal interface and an optional Tkinter desktop interface.

## Features

- Log and browse volunteer service records
- Validate names, dates, categories, and hours
- Assign sequential IDs to records
- Save records in JSON and import or export CSV files
- View service totals, averages, category summaries, and volunteer rankings
- Flag unusually long sessions
- Export Markdown and text audit reports
- Run an optional desktop interface with Tkinter
- Recover from missing or corrupted data files

## Requirements

- Python 3.10 or later
- No third-party packages required
- Tkinter is needed only for the optional GUI
